## Problème

Le endpoint `/api/instances` affiche des doublons pour certaines instances (boussad-agent, apacheco-agent, vjourne-agent, new-agent).

## Cause

La fonction `list_instances()` interroge l'API Kubernetes pour tous les pods avec le label `app=agent-instance`. Lorsqu'une instance a plusieurs pods (rollout, rollback, crashloop), chaque pod apparaît comme une entrée distincte dans le dashboard car ils ont des noms différents (hash aléatoire dans le nom).

## Fix

Regrouper les pods par label `agent-instance` et ne garder qu'un seul pod par subdomain (préférence pour les pods en phase Running).
